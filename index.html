    从图片 / 网页导入

    上传课表截图自动识别，或者把课表网页里的表格复制粘贴到下面；也支持保存的 HTML、JSON 和文本。导入前会先显示预览，确认无误再替换或追加。

    从课表截图导入
    支持 PNG / JPG / WEBP。图片只在浏览器里识别，不会上传到服务器。
    图片已选择
    首次识别会联网加载中文 OCR 模型（约 20MB），需要十几秒；之后浏览器会缓存。识别结果会放进下面的文本框，方便你校正。
    或者使用文本 / HTML / JSON
    导入格式说明
    • 图片 OCR：上传课表截图，程序会尝试按表格位置还原课程；截图越清晰、越正，效果越好，识别后仍建议核对。
    • 网页表格文本：在课表网页上选中整张表复制，粘贴进来。表头需要有「周一…周日」。
    • 网页 HTML：把课表网页另存为 .html 后上传，程序会读取其中的表格。
    • 逐行文本：一行一门课，字段用 | 分隔：课程名|老师|周一|1-2|1-16|明德楼|A418。
    • JSON：课程数组，至少包含 name / day / periods，可选 teacher / weeks / building / room / placeId。

    手动添加课程

    第一次编辑或添加时，会把当前课表复制成「我的课表」，之后随时可以点右上角「恢复内置课表」还原。

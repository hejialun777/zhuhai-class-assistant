# 课表助手 · 珠海科技学院

把课表截图 + 校园平面图做成一个可查询的网页，两个入口：**查看课表**、**路线查询**。

## 在线地址

**<https://hejialun777.github.io/zhuhai-class-assistant/>**

发这个链接给任何人，用电脑或手机浏览器打开即可，不需要装任何东西。
是 `https`，所以定位功能正常可用。

手机上可以「添加到主屏幕」，用起来和 App 差不多：
iOS Safari 点底部分享按钮 → 添加到主屏幕；Android Chrome 点右上角菜单 → 添加到主屏幕。

> 仓库是公开的，所以课表内容（上课时间、教室、老师姓名）是公开的。
> 不想公开就 `gh repo edit --visibility private`，但被搜索引擎抓取过的内容收不回来。

## 本地打开方式

**方式一（推荐，能用定位）**

双击 `启动.bat`，浏览器会自动打开 <http://localhost:8080/>。

需要本机装了 Node.js。没有的话，在文件夹里执行：

```
node serve.js --open
```

**方式二（最省事，但没有定位）**

直接双击 `index.html`。课表和路线计算都能用，只有「📍 定位我的位置」会被浏览器禁用——
此时改用「在地图上点选起点」即可，效果一样。

> 浏览器只在 `https://` 或 `localhost` 下才允许网页获取定位，这就是方式一存在的原因。

**手机连同一 WiFi 访问电脑**

电脑上跑 `node serve.js`，手机浏览器打开 `http://<电脑局域网IP>:8080/`。
校园网常开「客户端隔离」，可能连不通；而且 `http` 下定位会被禁用，得用「在地图上点选起点」。
所以手机用上面的在线地址更省事。

## 查看课表

- 顶部切换周次（默认停在本周，第 3 周 = 2026-09-14 ~ 09-20）。
- 顶部横幅实时显示**正在上的课 / 下一节课**倒计时，并按你当前位置估算出「建议几点前出发」。
- 搜索框支持课程名、老师、楼栋、教室号，命中的课程高亮、其余置灰。
- 点任意课程弹出详情，可一键跳到路线查询。

## 路线查询

1. 选起点：下拉框选地点，或点「📍 定位我的位置」用手机 GPS，或「在地图上点选起点」。
2. 选终点：下拉框，或直接在**课表里点课程 → 规划去这里的路线**，或在**地图上点任意地点**。
3. 切「步行 / 骑行」，结果显示距离、耗时和途经点。

地图上绿色实心点是上课地点，空心点是其他地点。点「显示路网」可以看到路线是沿着哪些路走的。

## 关于估算精度（重要）

耗时是**估算值**，不是导航实测。三个误差来源，都可以在「⚙ 设置」里调：

| 参数 | 默认 | 说明 |
|---|---|---|
| 地图比例 | 2.0 米/像素 | 示意图 1 像素代表多少米。这是最大的不确定项 |
| 步行速度 | 1.15 m/s | ≈ 4.1 km/h |
| 骑行速度 | 4.2 m/s | ≈ 15 km/h |

距离是沿**路网**算的（不是直线），所以会绕开湖心湖、碧瑶湖这些走不通的地方。
路网是按示意图上的主干道描的点，位置有估读误差。

## 文件说明

```
index.html        页面结构
css/style.css     样式
js/data.js        课表、地点坐标、路网、出行参数  ← 要改数据改这个
js/router.js      最短路径计算（纯算法，可单独测试）
js/app.js         界面逻辑
serve.js          本地静态服务器
启动.bat          双击启动
assets/map.jpg    校园平面示意图
tools/check.js    数据自检脚本
```

## 数据自检

改了 `js/data.js` 之后跑一下，能查出坐标越界、路网断开、课程时间冲突等问题：

```
node tools/check.js
```

# 珠科管家 · 珠海科技学院

把**课表、校园路线、每日待办和月历**放进一个网页里。纯静态前端，不依赖后端、数据库和构建工具，打开即用。

## 在线地址

**<https://hejialun777.github.io/zhuhai-class-assistant/>**

发这个链接给任何人，用电脑或手机浏览器打开即可，不需要安装任何东西。
是 `https`，所以定位功能正常可用。

手机上可以「添加到主屏幕」，用起来和 App 差不多：
iOS Safari 点底部分享按钮 → 添加到主屏幕；Android Chrome 点右上角菜单 → 添加到主屏幕。

> 页面和项目已经改名为「珠科管家」。GitHub 的仓库名只支持 ASCII 字母、数字和 `-_.`，
> 所以仓库 slug 仍保留 `zhuhai-class-assistant`，在线地址也因此不变。

## 现在有什么

### 课表查询（主页面）

- 默认打开就是课表；顶部切换周次（默认停在本周）。
- 下一节课横幅实时倒计时，并按你当前位置估算「建议几点前出发」。
- 搜索课程名、老师、楼栋、教室号，命中高亮、其余置灰。
- 点任意课程查看详情，可一键跳到路线查询。
- 课表可以继续使用内置示例，也可以在「我的 → 课表」里导入或手动修改。

### 全部待办 + 月历

- 主页面右侧（手机上是课表上方）有「全部待办」栏目。
- 输入任务、可选时间，按回车或「添加」。
- 点圆圈标记完成：完成的任务变暗并加删除线，再点一次可恢复。
- 上方有按周排列的「每日任务栏」，切换日期就切换当天的任务；切到其他周时课表也跟着翻到那一周。
- 点「📅 月历」打开月视图，有任务的日期会显示任务摘要；点日期跳回那天的待办。

### 路线查询

1. 选起点：下拉框选地点，或点「📍 定位我的位置」用手机 GPS，或「在地图上点选起点」。
2. 选终点：下拉框，或直接在课表里点课程 → 规划去这里的路线，或在地图上点任意地点。
3. 切「步行 / 骑行」，结果显示距离、耗时和途经点。

速度、地图比例等**设置已经移到路线查询页**（点「⚙ 设置」展开）。
地图上绿色实心点是上课地点，空心点是其他地点；点「显示路网」可以看到路线沿哪些路走。

### 我的

左侧（手机上是顶部）有三个小分支：

- **用户**：头像和显示名字。可以选一个 emoji，也可以上传图片当头像。
- **课表**：网页导入、手动输入、查看/编辑/删除当前课表。
- **切换用户**：注册、登录、退出、切换到本机的其他用户。

## 本机账号（重要）

因为这是 GitHub Pages 上的纯静态网页，没有服务器，**账号不是学校统一认证**：

- 用户名、密码摘要、头像、课表、待办都只保存在当前浏览器的 `localStorage` 里；
- 不同用户在同一台浏览器里可以各自拥有独立的课表和待办；
- 换电脑、换浏览器或清除浏览器数据后，这些内容不会自动同步，也无法找回；
- 密码用 SHA-256 加盐后保存摘要，但它的定位是「本机多用户配置」，不是真正的在线账号系统。

如果以后需要真正的跨设备登录，需要接入后端或 Supabase / Firebase 之类的服务。

## 课表导入

「我的 → 课表 → 网页导入」支持四种输入：

1. **从网页复制出来的表格文本**：在课表网页上选中整张表复制，粘贴进来。表头需要有「周一…周日」。
2. **保存下来的网页 HTML**：把课表网页另存为 `.html` 后上传，程序会读取其中的表格。
3. **逐行文本**：一行一门课，字段用 `|` 分隔：
   ```
   课程名|老师|周一|1-2|1-16|明德楼|A418
   ```
4. **JSON 课程数组**：
   ```json
   [
     { "name": "高等数学A I", "teacher": "甄苓", "day": 1, "periods": [5, 6],
       "weeks": { "type": "range", "from": 1, "to": 16 },
       "placeId": "bowen", "room": "阶梯D301" }
   ]
   ```

导入前会先显示预览和「需要注意」的提示。确认后可以**替换**当前课表，也可以**追加**课程。
网页课表没有统一格式，解析采用尽力而为的启发式；如果老师、节次或地点识别得不对，
可以到「手动输入」里编辑，或者直接在「当前课表」里修改。

「手动输入」可以设置课程名、老师、星期、起止节次、周次、楼栋、教室和颜色。
第一次编辑或添加时，会把当前课表复制成「我的课表」，之后随时可以点「恢复内置课表」还原。

## 本地打开方式

**方式一（推荐，能用定位）**

双击 `启动.bat`，浏览器会自动打开 <http://localhost:8080/>。

需要本机装了 Node.js。没有的话，在文件夹里执行：

```
node serve.js --open
```

**方式二（最省事，但没有定位）**

直接双击 `index.html`。课表、待办、路线计算都能用，只有「📍 定位我的位置」会被浏览器禁用——
此时改用「在地图上点选起点」即可，效果一样。

> 浏览器只在 `https://` 或 `localhost` 下才允许网页获取定位，这就是方式一存在的原因。

**手机连同一 WiFi 访问电脑**

电脑上跑 `node serve.js`，手机浏览器打开 `http://<电脑局域网IP>:8080/`。
校园网常开「客户端隔离」，可能连不通；而且 `http` 下定位会被禁用，得用「在地图上点选起点」。
所以手机用上面的在线地址更省事。

## 关于路线估算精度（重要）

耗时是**估算值**，不是导航实测。三个误差来源，都可以在路线查询的「⚙ 设置」里调：

| 参数 | 默认 | 说明 |
|---|---|---|
| 地图比例 | 2.0 米/像素 | 示意图 1 像素代表多少米。这是最大的不确定项 |
| 步行速度 | 1.15 m/s | ≈ 4.1 km/h |
| 骑行速度 | 4.2 m/s | ≈ 15 km/h |

距离是沿**路网**算的（不是直线），所以会绕开湖心湖、碧瑶湖这些走不通的地方。
路网是按示意图上的主干道描的点，位置有估读误差。

### 校准地点位置

**六教**（M515 上课地点）示意图上没有标注，按「敏学楼右上方空地、靠近球场」放在了敏学楼
东北侧（图上约 712, 274），仍用 **?** 标出，建议实地核对一次。

操作：路线查询 →「校准地点位置」→ 拖动圆点到正确位置 → 点「保存」。
改完存在本机浏览器里，只影响你这台设备；点「还原」可以恢复默认。

## 文件说明

```
index.html        页面结构
css/style.css     样式
js/data.js        内置课表、地点坐标、路网、出行参数  ← 要改内置数据改这个
js/router.js      最短路径计算（纯算法，可单独测试）
js/store.js       本机账号、登录状态、每个用户的课表与待办
js/import.js      网页 / HTML / 文本 / JSON 课表解析
js/app.js         界面逻辑：课表、待办、月历、我的、路线、地图
serve.js          本地静态服务器
启动.bat          双击启动
assets/map.jpg    校园平面示意图
tools/check.js    数据与页面自检脚本
```

## 数据自检

改了 `js/data.js` 之后跑一下，能查出坐标越界、路网断开、课程时间冲突等问题：

```
node tools/check.js
```
